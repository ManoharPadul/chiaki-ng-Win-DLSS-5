# Chiaki-ng Windows DLSS 5

**PlayStation Remote Play on Windows with a custom DLSS 5 integration.**

Chiaki-ng-Win-DLSS-5 is a modified Windows build of Chiaki-ng, designed to bring PlayStation 5 Remote Play together with a custom DLSS 5 graphics-enhancement implementation.

The goal is to explore enhanced visuals while streaming PS5 gameplay to a Windows PC, with an emphasis on image quality, responsiveness, and practical gaming performance.

## Features

- **PS5 Remote Play:** Connect to and stream gameplay from a compatible PlayStation 5.
- **Windows-focused build:** A customized version targeting Windows users.
- **Custom DLSS 5 integration:** Incorporates the project's DLSS 5 implementation.
- **Graphics experimentation:** Intended for testing visual enhancements during gameplay streaming.
- **Performance testing:** Evaluate image quality, latency, frame pacing, and GPU utilization on supported hardware.

> Feature availability and performance depend on the build, graphics hardware, drivers, configuration, and the implementation used.

## Project Status

**Experimental — active development**

This project is intended for enthusiasts interested in PlayStation Remote Play and PC graphics technology.

Compatibility, visual quality, stability, and performance should be tested on each supported configuration before the build is considered production-ready.

## Requirements

- Windows 10 or Windows 11, depending on build compatibility
- A compatible PlayStation 5 and network connection
- A supported GPU and graphics driver for the implemented enhancement features
- The required runtime libraries and dependencies for the supplied build

Consult the release notes for build-specific requirements.

## Installation

1. Open the project's GitHub Releases page.
2. Download the Windows package attached to the relevant release.
3. Extract the portable package or run the installer, depending on the package supplied.
4. Launch the application.
5. Configure and connect your PS5 using the application's Remote Play setup.
6. Enable the supported graphics-enhancement options, if available in your build.
7. Test image quality, responsiveness, and stability.

Only download executable files from the project's official release page.

## Testing and Feedback

When reporting a problem, include:

- Windows version
- GPU model and driver version
- PS5 model and connection type
- Stream resolution, frame rate, and bitrate
- Whether the custom graphics enhancement was enabled
- Steps to reproduce the issue
- Relevant application logs and screenshots

Please distinguish actual measured results from visual impressions.

## Known Limitations

- Compatibility may vary across Windows versions and GPU configurations.
- Graphics enhancements may introduce artifacts, additional GPU load, or latency.
- Streaming quality depends on network conditions and the configured Remote Play settings.
- Not every advertised enhancement may be available in every build.
